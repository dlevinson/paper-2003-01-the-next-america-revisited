# Data Notes

This folder contains the compact supporting-data subset for "The Next America Revisited."

## Original Files

- `original/census/AgeMix.xls`: Excel workbook for Columbia age distribution, matching Figure 8.
- `original/census/ColumbiaCensus1990.txt` and `original/census/1990CensusData.doc`: 1990 Census STF source extracts for Columbia.
- `original/census/Race.xls` and `original/census/Race.txt`: race, housing value, and rent calculations used in Table 1.
- `original/housing/Apartments.xls` and `original/housing/Apartments.txt`: author-compiled apartment rent data used in Table 2.
- `original/schools/HowCoSchooldatabase.xls`: Howard County school enrollment/race data and dissimilarity calculations used in Tables 3 and 4.
- `original/schools/ExtraTable.doc`: additional school table context from the same source set.
- `original/village_centers/VillageCenterTable.doc`: author-compiled village-center comparison notes used for Figure 2.
